CONTEXTSHIFT

Privacy Policy

Effective: May 9, 2026

TL;DR — ContextShift collects zero data. Everything stays in your browser. We have no servers, no analytics, no tracking. Your conversations and API key never leave your machine.

What is ContextShift

ContextShift is a browser extension that exports AI conversations and generates handoff prompts so you can seamlessly continue your work across different AI platforms. It runs entirely in your browser.

Data We Collect

None.

ContextShift does not collect, transmit, store, or process any personal data on any server. There is no backend. There is no database. There are no servers.

What's Stored Locally

The following data is stored exclusively in your browser using Chrome's built-in storage APIs:

  • Your settings — export format preference, toggle states. Stored in chrome.storage.local.
  • Anthropic API key — if you choose to enter one for handoff prompt generation. Stored in chrome.storage.local. Never transmitted anywhere except directly to Anthropic's API when you explicitly click "Generate Handoff Prompt".
  • Exported conversations — saved to your browser's IndexedDB for the conversation library feature. Never leaves your device.
  • Last handoff prompt — cached locally for the Quick Paste feature.

You can delete all stored data at any time from the extension's Settings tab.

Third-Party Services

ContextShift makes one optional external API call:

  • Anthropic API — When you click "Generate Handoff Prompt", your conversation text is sent to Anthropic's API (api.anthropic.com) to generate a context summary. This uses your own API key that you provide. This call only happens when you explicitly initiate it.

Anthropic's handling of API data is governed by Anthropic's Privacy Policy. Per their API terms, data sent via the API is not used to train their models.

No other external services, servers, APIs, or third parties receive any data from this extension.

Cookies & Tracking

ContextShift uses:

  • Zero cookies
  • Zero analytics
  • Zero telemetry
  • Zero tracking pixels
  • Zero fingerprinting

We don't know who you are, what you export, or when you use the extension. That's by design.

Extension Permissions

ContextShift requests the following browser permissions:

  • storage — Save your settings and conversation library locally in your browser
  • tabs — Detect which AI platform you're currently on
  • scripting — Run content scripts to read conversation content from supported AI platforms
  • downloads — Save exported conversation files to your computer
  • activeTab — Access the current tab to scrape the active conversation
  • Host permissions — Limited to supported AI platform domains only (claude.ai, chat.openai.com, chatgpt.com, gemini.google.com, grok.com, perplexity.ai, phind.com, you.com)

Data Security

Since all data remains in your browser's local storage, security is handled by your browser's built-in sandboxing and encryption mechanisms. We cannot access, read, or recover your data — because we never have it.

Your API key is stored using chrome.storage.local, which is sandboxed to the extension and inaccessible to websites or other extensions.

Children's Privacy

ContextShift is not directed at children under the age of 13 and does not knowingly collect any information from children. Since the extension collects no data at all, this is inherently enforced.

Changes to This Policy

If this privacy policy is updated, the changes will be reflected on this page with a new effective date. Since ContextShift has no way to contact users (we don't have your email or any identifier), checking this page is the only way to stay informed.

Open Source

ContextShift is open source. You can audit every line of code to verify these claims. The extension contains no obfuscated code, no hidden network calls, and no bundled tracking libraries.
